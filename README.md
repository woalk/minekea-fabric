# Minekea Rewalked

_Simple, functional, decorative blocks._

- Stairs, slabs, vertical stairs, walls for many vanilla blocks
- Various furniture items (stools, chairs, tables, shelves, etc.)
- Functional window shutters
- Storage blocks for additional items (food, dyes, etc.)
- Barrels and crates for all kinds of wood
- Endless Rod (End Rod without base)
- and a few more helpful additions

## Compatibility

This mod is compatible with Fabric on Minecraft 26.2.

It requires Fabric API, [ChimericLib](https://www.curseforge.com/minecraft/mc-mods/chimericlib)
and [Architectury API](https://modrinth.com/mod/architectury-api).

## Origin

This mod is a rework of [Minekea](https://www.curseforge.com/minecraft/mc-mods/minekeamod),
a mod by ChimericDream.
It was forked from version
[26.2-10.1.0 from the Monorepo](https://github.com/chimericdream/minecraft-mods/tree/minekea/26.2-10.1.0/minekea).
This version of the mod was licensed under [MIT License](https://github.com/chimericdream/minecraft-mods/blob/minekea/26.2-10.1.0/minekea/LICENSE).

Due to the nature of ChimericDream's monorepo setup, the Git history of this fork is lost.
There is no plan to upstream these changes.

Only the Fabric version was extracted.
While we still currently depend on Architectury API,
the Architectury build setup is no longer used for simplicity.
